# 📁 Videotron SMAN 1 Balong – Configuration Files

Repositori ini berisi kumpulan file konfigurasi yang digunakan untuk pengaturan (*setting*) videotron di lingkungan **SMAN 1 Balong**. Repositori ini mencakup konfigurasi IC decoder, file pendukung pengaturan panel LED, serta dokumentasi visual terkait koneksi dan pemetaan panel videotron.

---

## 🧩 Isi dan Fungsi File

- **`RCG P2.5 GKGD ICN1065L DP32030.zip`**  
  Berisi file konfigurasi IC decoder **ICN1065L** dan **DP32020B** yang digunakan sebagai referensi dalam proses konfigurasi panel LED videotron.

- **`image/`**  
  Folder dokumentasi visual yang berisi gambar koneksi panel, pemetaan LED (*LED mapping*), layout pemasangan, dan dokumentasi teknis lainnya.

- **`README.md`**  
  Dokumen utama yang menjelaskan isi repositori, fungsi file konfigurasi, serta catatan teknis dalam proses pengaturan videotron.

### 🎯 Tujuan Konfigurasi

File konfigurasi disediakan sebagai referensi teknis untuk membantu proses pengaturan panel videotron agar sesuai dengan karakteristik perangkat keras yang digunakan.

Konfigurasi yang tepat perlu disesuaikan dengan jenis modul LED, kartu penerima (*receiving card*), sistem kontrol, serta susunan panel yang terpasang.

## 📝 Catatan Penting

> **Perhatian:** File konfigurasi di dalam repositori ini digunakan sebagai referensi teknis untuk pengaturan videotron SMAN 1 Balong. Pastikan konfigurasi IC decoder sesuai dengan tipe modul LED dan perangkat kontrol yang digunakan sebelum diterapkan pada panel.

- Simpan salinan konfigurasi asli sebelum melakukan perubahan.
